# Fluxx Engine

**Cross-platform, modular game engine with intuitive UI for building, animating, and deploying games.**

🌐 **Live Website:** https://thedevoffluxxengine.github.io/Fluxx-Engine/

---

## Features

* **Cross-platform:** Works on macOS and Windows (Linux coming soon)
* **User-friendly UI:** Easy-to-use interface for both beginners and professionals
* **Modular Design:** Add, remove, or customize engine components easily
* **High Performance:** Smooth animations and fast rendering powered by a custom engine architecture
* **Future-ready:** Designed to scale from small prototypes to immersive worlds

---

## Demo / Screenshots

Fluxx Engine is currently being developed using:

* **C++** for the core engine systems and rendering
* **Java** for security and protection systems
